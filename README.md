# Château Café

Projeto de Autoria Web desenvolvido no 2º semestre do curso de **Análise e Desenvolvimento de Sistemas — UFRN/EAJ**.

Uma aplicação web para visualizar cafés, adicionar produtos ao carrinho e finalizar a compra.

## Funcionalidades

- Catálogo de cafés consumido por uma API local.
- Adição e remoção de produtos no carrinho.
- Controle de quantidade.
- Cálculo automático do valor total.
- Formulário com pagamento e forma de recebimento.
- Design responsivo.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap
- JSON Server
- Local Storage

## Como executar

Na pasta `Cafeteria`, execute:

```bash
npm install
npx json-server db.json
```

Depois, abra o arquivo `Cafeteria/HTML/index.html` em um servidor local.
